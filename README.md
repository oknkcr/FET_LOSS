# FET_LOSS
FET_LOSS Calculator Tool

## Description

***FET_LOSS*** calculates Conduction Losses, Switching Losses, Gate Drive Losses, Body Diode Losses.

| **Loss Type** | **Key Parameters**                             | **Typical Source**  |
| ------------- | ---------------------------------------------- | ------------------- |
| Conduction    | R<sub>DS(on)</sub>, I<sub>D</sub>              | On-state resistance |
| Switching     | V<sub>DS</sub>, I<sub>D</sub>, f<sub>sw</sub>  | Transitions on/off  |
| Gate Drive    | Q<sub>g</sub>, V<sub>gs</sub>, f<sub>sw</sub>  | Driver circuitry    |
| Body Diode    | V<sub>f</sub>, t<sub>dead</sub>, I<sub>D</sub> | Freewheeling phase  |


## How to Use

just open **FET_LOSS.html** in your browser.
